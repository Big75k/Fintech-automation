# Fintech Automation — End-to-end Data Science Pipelines

This repository contains polished, production-oriented examples for credit risk and customer churn automation, including synthetic data generation, training pipelines, model artifacts, reporting, and CI.

TL;DR
- Dataset: synthetic credit + churn data (see data/raw)
- Models: RandomForest (credit), XGBoost (churn)
- Quickstart: see Quickstart section below

Quickstart
1. Clone this repo
2. Create environment: `pip install -r requirements.txt`
3. Generate data and run pipeline: `bash scripts/run_pipeline.sh`

Contents
- src/ — production-ready scripts
- data/ — synthetic data generator and notes
- models/ — trained model artifacts (generated by pipeline)
- reports/ — auto-generated figures and PDF
- tests/ — pytest tests
- .github/ — CI workflows
